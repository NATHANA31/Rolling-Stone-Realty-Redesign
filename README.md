# Rolling Stone Realty: redesign concept
Plain HTML, CSS and JS. No build step. Open index.html, or upload the folder to GitHub Pages or Netlify.
- Edit estates, prices, services, team and reviews in js/data.js.
- Forms: paste a Formspree or Web3Forms URL into CONFIG.formEndpoint in js/data.js. Without one they run in demo mode.
- Hero videos: add MP4s named after each estate slug (e.g. assets/videos/elite-city.mp4).
- Replace [Your Name] in js/main.js, and the [Placeholder] text in js/data.js, before sending.
